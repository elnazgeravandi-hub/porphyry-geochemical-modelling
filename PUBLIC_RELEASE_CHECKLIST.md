# Public-release checklist

This package contains source and synthetic generators only, without private inputs or local generated outputs.

Before publication:
- Confirm data-owner restrictions stated in DATA_AVAILABILITY.md.
- Confirm Bartlett scoring, component retention/order, score shifting and breakpoint selection against the actual study. The images and supplied plotting/clipping snippets do not establish these details.
- Do not call this package the exact original study implementation until that comparison is complete.
- Keep private input data and locally generated real-data results outside the upload. Git ignore rules are helpful but do not remove files already tracked.
- Check every upload; no tokens, credentials, private coordinates, identifiers, screenshots or personal paths.
- Publish as the revised computational workflow; update manuscript and response-letter URLs only after upload and verification.

No GitHub repository has been created or deleted by preparing this archive.
